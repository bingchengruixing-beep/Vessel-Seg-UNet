# 更新说明

## 本次更新

- 增加 DIAS 目标域平衡采样，可控制每轮目标域样本占比。
- 增加按患者/序列分组的 3～5 折交叉验证，并将各折权重分目录保存。
- 增加最多 5 个模型的概率集成推理、批量推理和阈值扫描。
- 增加 2.5D 前/当前/后时相输入；缺少配对时相时自动退化为当前图重复输入。
- 优化 1024 分辨率训练速度：常驻 DataLoader worker、预取、解码缓存、2.5D 中心帧去重解码，以及等价的快速 Zhang-Suen 骨架化。
- Web 阈值扫描增加验证集口径选择：DIAS 外部验证集或当前 K 折验证集；默认使用 DIAS 外部验证集，避免与历史结果混淆。
- 阈值扫描默认采用 0.05 粗扫后在最佳点附近以 0.01 精扫，并支持自定义阈值列表。

## 重要评估口径

- 历史 `0.7453` 使用 DIAS 外部验证集；K 折内部验证集的 Dice 不应直接与它比较。
- 使用 2.5D 模型时，三张图必须属于同一患者/序列并按前、当前、后顺序输入；单图推理会自动重复当前图。
- 训练权重、日志、测试截图和本地运行产物不作为源码提交内容。

## 主要文件

- `src/dataset.py`：采样、分组、2.5D 和 DataLoader 优化。
- `src/skeleton.py`：保持输出一致的快速骨架化实现。
- `web_server.py`：训练、推理、集成和双口径阈值扫描接口。
- `web_static/index.html`、`web_static/app.js`：Web 配置和评估口径控件。
- `configs/default.yaml`：默认训练与性能配置。
