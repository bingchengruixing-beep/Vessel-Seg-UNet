# Vessel-Seg-UNet 项目工作总结(汇报版)

> 时间:2026-08-23 ~ 2026-08-25 ｜ 平台:RTX 4060 Laptop 8GB ｜ 数据:自有标注 177 对 + 开源于集 50 对

---

## 一、项目背景与目标

对**脑血管 DSA 造影图像**做二值语义分割,核心难点:血管前景仅占 6%~13%、末梢细支 1~3 像素宽,类别极度不平衡且拓扑连通性至关重要。

本次工作围绕三件事:**① 架构评审与问题修复 → ② 模型优化 → ③ 全量对比实验**。

## 二、工作内容总览

### 阶段 1:架构评审与 8 项修复

通读全部源码(约 3000 行),确认架构分层合理(CLI/Web 共用核心、预测管线唯一、检查点安全加载),并修复 8 类问题:
未使用依赖、Windows 中文路径崩溃、早停指标受 batch 影响、空预测指标错误、Dice 损失被大前景主导、无法选设备、Web 并发竞态、测试薄弱。

### 阶段 2:模型优化(全部向后兼容)

| 优化 | 说明 |
|------|------|
| **Focal Tversky 损失** | α=0.7 加重"漏检细血管"惩罚 |
| **clDice 中心线监督** ★ | 自研 Zhang-Suen 骨架化(纯 numpy)+ 可微软骨架,不改架构、零新依赖 |
| warmup + 余弦退火 | 前 5 epoch 线性预热,稳定早期训练 |
| 梯度裁剪 + EMA 权重 | AMP 下防 loss 尖峰;验证/保存均用 EMA,保证"测的=部署的" |
| 固定随机种子 | seed 42,实验完全可复现 |

### 阶段 3:环境与数据治理

- **环境**:从零搭建(无 torch、网络受限),攻克沙箱 TLS、代理卡死、镜像源、依赖需 C 编译器 4 个大坑,最终 CUDA 版 torch 2.10 在 RTX 4060 上正常训练;
- **完整数据集**:177 对自有标注,构建训练管线并处理三类数据问题——35 张软标注概率图二值化、5 对图像/掩膜尺寸错位(含转置)对齐、跨组重名前缀;
- **发现并修复一个隐蔽 bug**:图像/掩膜尺寸不一致时 albumentations 补边错位导致训练崩溃,双层修复并加回归测试。

### 阶段 4:全量对比实验

- **预实验**(DIAS 开源于集 50 对):4 组对照(基线/Focal Tversky/clDice/Attention 组合);
- **主实验**(完整数据集 177 对,150/27 划分):基线 vs clDice,全部训练策略统一(AdamW 1e-4、warmup+cosine、clip 1.0、EMA 0.999、seed 42、AMP)。

## 四、核心结论

1. **clDice 中心线监督是最大收益点**:在两类数据上分别 +1.7pp / +1.4pp Dice,且 Recall 同步提升、Precision 不降——"逼网络保住血管连通性"同时找回了细支像素,结论可复现;
2. **Focal Tversky 按设计工作**:Recall +9.7pp,适合"少漏血管"优先的场景;
3. **小数据上应优先损失改进而非加大模型**(Attention 组合在 30 张数据上过拟合);
4. **默认后处理对细血管有害**(删真实细支,Dice -2pp 级),已按数据重标定并建议默认关闭;
5. **数据质量是隐性瓶颈**:软标注、尺寸错位等 3 类问题 + 1 个管线 bug 均在实验中暴露并被修复。
