# 三模型版本 · 使用说明（给组员）

这是「三模型」实验版本，和仓库根目录的 `Vessel-Seg-UNet/`（重构版）**并列、互不依赖**。
本文件夹是独立的一套：三个 U-Net 变体模型 + 14 次对比实验 + 最优权重。

---

## 一、三个模型是什么

| 模型 | 文件 | 注册名（config 里的 `model.name`） |
|---|---|---|
| U-Net 基线 | `src/models/unet.py` | `unet_baseline` |
| Attention U-Net | `src/models/attention_unet.py` | `attention_unet` |
| U-Net + 预训练 ResNet34 | `src/models/unet_resnet.py` | `unet_resnet` |

三者输入输出契约一致：输入 `(B,1,H,W)` 灰度图，输出 `(B,1,H,W)` **原始 logits（无 Sigmoid）**。

---

## 二、最优权重

`weights/best_model_fixed.pth` —— **实验 12（正确性修复版）的最优模型，验证 Dice 0.7302**（全场最高）。

- 架构：`unet_resnet`（U-Net + ImageNet 预训练 ResNet34 编码器）
- 对应配置：`configs/unet_resnet_mixed_lowlr_fixed.yaml`
- 纯权重（只含 `model_state_dict`，去优化器状态，98MB），可直接加载，无需训练

`weights/best_model.pth` —— 实验 11（修复前）权重，验证 Dice 0.7273，对应 `configs/unet_resnet_mixed_lowlr.yaml`（如需复现旧结果）。

`weights/best_model_crossval.pth` —— 实验 13（跨源划分口径）权重，**本地同域验证 Dice 0.7760 / DIAS 跨源测试 Dice 0.6524**，对应 `configs/unet_resnet_mixed_lowlr_crossval.yaml`。用于评估真实跨源泛化能力（见第六节 domain gap 说明）。

`weights/best_model_crossval14.pth` —— 实验 14（半跨源口径）权重，**本地同域验证 Dice 0.7889 / DIAS-val 20 跨源测试 Dice 0.7247**，对应 `configs/unet_resnet_mixed_lowlr_crossval14.yaml`。训练混入 30 张 DIAS-train，较纯跨源 +0.077（见第六节）。

## 三、怎么用它评估（重要）

⚠️ **`--config` 和 `--checkpoint` 必须配对**：config 决定构建什么架构，checkpoint 决定灌什么权重。
架构对不上（比如用 U-Net 去加载 ResNet 权重）会直接报 shape 错误。

```bash
python evaluate.py \
  --checkpoint weights/best_model_fixed.pth \
  --config configs/unet_resnet_mixed_lowlr_fixed.yaml
```

配对规则一句话：**config 的 `checkpoint.save_dir` 指向哪个目录，就用哪个目录下的权重配同一个 config。**
完整映射见 `reports/experiments_comparison.md`。

## 四、环境

- Python 3.10+，PyTorch 需 **CUDA 版**（CPU 版也能跑推理，但训练慢）
- 安装依赖：`pip install -r requirements.txt`
- 训练入口：`python train.py --config configs/xxx.yaml`
- 单张推理：`python inference.py`

---

## 五、⚠️ 数据路径要改

所有 `configs/*.yaml` 里的数据路径是**我本机的绝对路径**（形如 `E:/Unet模型训练/数据集-标注完成/...`），
在你自己电脑上跑之前，**必须改成你自己的数据目录**，否则报找不到文件。

## 六、14 次实验结论

完整对比（每轮的 Dice / IoU / Precision / Recall / 早停 epoch）在 `reports/experiments_comparison.md`。

核心结论一句话：**数据量 > 更强的初始化 > 换模型架构**；此外，损失函数的实现细节（Dice 逐样本平均 vs batch 求和）也会系统性改变 P/R 平衡（实验 12，Recall 0.734→0.756）。

实验 13 用「跨源划分」（本地训练/验证 + DIAS 独立测试）首次测出**真实 domain gap ≈ 0.12**：同域 Dice 0.776、跨源测试 0.652，且跨源瓶颈在**误检**（Precision 0.58 << Recall 0.82）而非漏检。

实验 14 用「半跨源划分」（本地 142 + 30 张 DIAS-train）测出：**30 张目标域数据 = 跨源 +0.077**（DIAS-val 20 从 0.648 提到 0.725），且几乎全部来自「治愈误检」（Precision 0.57→0.73）。同时反证实验 12 的 0.7302 基本无早停泄漏（差 0.0055）。
